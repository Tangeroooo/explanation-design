# 고정 다이어그램 테마

새 그림은 이 밝은 배경과 역할별 팔레트로 제작한다. 견본 가이드의 연한 채움·색상 외곽선·중립색 배경 구조·그림 간 역할 일관성을 따른다. 테마는 이미 선택되었으므로 온보딩 질문으로 되돌리지 않는다. 이후 사용자가 다른 스타일을 명시적으로 요청하면 그 요청을 우선한다.

## 스타일 질문 없이 진행한다

- 테마 선택, 브랜드 URL·색상 토큰 제공, 기본값 유지, 프로필 불러오기·저장, 스타일 견본 승인을 묻지 않는다. 다이어그램 유형·크기·제작 계획의 확인 답변도 기다리지 않는다. 독자의 질문과 실제 표시 크기에 맞게 선택하고, 결과에 영향을 주는 가정을 알린 뒤 진행한다.
- 이 reference를 선택된 스타일과 상시 진행 지침으로 `diagram-design`에 전달한다. 제작자의 기본 팔레트·혼합 폰트·스타일 온보딩·프로필 저장 제안·그리기 전 확인 대기를 대체한다. 레이아웃·export·검증 지침은 계속 따른다.
- 현재 산출물이나 작업 전용 템플릿에 토큰을 적용한다. 온보딩 조건을 맞추려고 공유 스킬 설치본이나 전역 프로필을 수정하지 않는다. 발견한 저장 프로필로 이 테마를 조용히 교체하지 않는다.
- 내용·근거·출력 제약의 누락으로 올바른 결과를 만들기 어려울 때만 질문한다. 일상적인 시각 선택을 질문으로 돌리지 않는다.

## 글꼴과 export

제목·노드 이름·식별자·연결선 라벨·범례·캡션 등 그림에 보이는 모든 글자는 한국어와 라틴 문자 모두 **Noto Sans KR**을 쓴다. 위계는 다른 폰트가 아니라 굵기와 크기로 표현한다(일반 400, 강조 700). HTML/SVG에는 `font-family: "Noto Sans KR", sans-serif`를, plotting 도구에는 같은 실제 글꼴을 설정한다. 대체 글꼴은 표시 실패에 대비한 것이며 요청한 폰트가 렌더되었다는 증거가 아니다.

라벨 측정·배치·export 전에 폰트를 로드한다. 출력과 같은 폰트·굵기로 측정하고 줄을 나눈다. CSS 선언만 보지 말고 실제 렌더된 폰트와 한글·라틴 글리프를 확인한다. 이식 가능한 SVG/HTML은 출력 형식과 라이선스가 허용하는 방식으로 폰트를 포함하거나 동봉한다. 글자를 경로로 바꿀 때도 편집 가능한 텍스트 원본을 보존한다. PNG는 래스터화 전에 폰트를 확인한다. 폰트 로드·포함이 실패하면 한계를 밝히고, 폰트 검증 통과를 주장하거나 제작자의 기본 폰트로 조용히 바꾸지 않는다.
