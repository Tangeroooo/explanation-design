# 그림 제작 명세

- ID / 제목:
- 독자가 해결할 질문 / 그림으로 가능해져야 할 구체적인 추적·비교·예측·판단:
- 한 문장 핵심 메시지:
- 대상 독자 / 필요한 선행 개념:
- source ID·위치·버전 / claim ID:
- 시각 유형 / 문장·표보다 나은 이유:
- 상위 그림 / 상위 요소·edge와 이 그림의 대응 / 집계·추가 세부·관점 전환:
- 포함 요소 / 각 요소의 의미:
- 시각적 어휘: 역할별 색·도형·포함·위치와 축·선 종류·크기 / 색 이외의 구분:
- 관계 / 방향 / edge 라벨 / 관계별 근거:
- 상태 / guard / 실행 순서 / 보장하지 않는 순서:
- 사실·추론·제안·미확인 표현 (색 이외의 구분 포함):
- 원본 수치 / 단위 / 계산 코드 (해당 시):
- 정확한 라벨:
- 캡션:
- 생략·집계 / 해석에 미치는 영향:
- 끝까지 추적할 구체적 예시 / 예시 수치 표시 / 추상화해도 남길 경계와 구분:
- 비교하는 경우: 공통 기준 / 달라지는 것 / 약하게 표시할 공통 배경:
- 크기 / 세부 수준:
- 선택된 스타일: [고정 역할별 팔레트](../references/diagram-theme.ko.md), 모든 글자 Noto Sans KR. 테마·프로필 질문이나 제작 전 승인 대기 없음. 사용자가 명시한 변경이 있으면 기록:
- 폰트 로드 / 실제 렌더된 폰트·글리프 검증 / 이식 가능한 export 처리:
- 출력 형식:
- 의미 수용 기준 / 조건을 바꾼 질문 / 예상 결과 또는 명시적인 미확인과 그 근거:
- 시각 수용 기준:
- 그림의 수정 원본 / 주장 변경 시 다시 만들 산출물 / 해당 시 확인할 게시 화면:
- 제작에 사용한 diagram-design 위치·버전 (제작 시 발견한 값):
- 독립 평가 대상인 경우: 1단계 독자 자료(렌더·버전, 표시 크기, 독자 질문·대상, 실제 독자에게 보이는 문맥) / 2단계 근거 자료(필요한 명세 발췌, 테마·명시적 변경, 버전 있는 출처, 도구 관측; 제작자 자기평가·benchmark 정답 제외):
- 평가 기록: 첫 해석 / 지적과 처리 결과 / 재생성 버전 / 수정·재평가 횟수(최대 두 차례) / 미해결 문제 또는 평가 불가:
- 결과 / 검증 명령 / 실제 관찰 / 수정 / 미검증 범위:
