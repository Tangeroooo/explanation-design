# 실제 적용 평가

문구 일치 대신 관측 가능한 판단을 평가한다. cases.json의 criteria는 평가자용이며 독립 실행 agent에 정답으로 주지 않는다.

각 항목: 0 = 누락·오류, 1 = 일부 충족·한계 명시 부족, 2 = 근거와 조건을 포함해 충족. 합계 점수보다 결론을 바꾸는 결함을 우선한다.

- 핵심 질문에 직접 답함.
- 중요한 주장과 출처·버전·조건 연결.
- 인과·실행 순서의 비약 없음.
- 사실/추론/제안/미확인 구별.
- 제약·실패 경로와 선택 전환 조건 포함.
- 표현이 이해를 도우며 과잉 제작 없음.
- 본문·표·그림의 의미 일치.
- 독자가 결론과 한계를 설명할 수 있음.

구조 검사 결과, 근거·의미 평가, 실제 render 시각 검토는 별도로 기록한다. 실행하지 않은 case는 미실행이다. 합성 fixture는 production 검증이 아니다. 발견한 결함 → 일반적인 수정 → 해당 사례 재확인을 남긴다.
